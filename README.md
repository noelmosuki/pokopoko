# しごと時間 — iPad 向け操作プロトタイプ

iPad の Safari などで動く HTML/CSS/JavaScript の試作です。ネイティブ iOS アプリ・App Store 配布版ではありません。外部ライブラリやインストールは不要です。

## 起動

```sh
cd /workspace/pokopoko
python3 -m http.server 8001 --bind 127.0.0.1
```

このコマンドはクラウド環境内の動作確認用です。実機 iPad で使うには、iPad からアクセスできる HTTPS サーバーへの配置が必要です。

## 操作

- 8人まで個別に開始・一時停止・再開。名前または「カラー変更」を押すと名前とテーマカラーを変更できます。8色から担当者ごとに選べて、端末に保存されます。
- 完了で項目を複数選び、登録。登録時点の金額と作業時間を保存し、タイマーをリセットします。同じ項目を複数個登録する数量入力は未実装です。
- 項目の取り込み：スプレッドシートの A列（項目）・B列（整数の円金額）を、見出しなしの2列でコピーして貼り付けます。直接の Google Sheets API 連携ではありません。
- 労働時間入力：担当者別に0〜24時間を入力。7時間30分は7.5です。
- 日計：担当者別の当日受注額 ÷ 入力した労働時間を表示。0時間の場合は「時間未入力」。日計 CSV をダウンロードできます。

データはブラウザの localStorage に保存します。同じ端末・ブラウザ・オリジンでのみ継続利用でき、共有・バックアップ・認証は未実装です。ブラウザデータの削除で消失します。日付は端末のローカル日付を使い、深夜をまたぐ作業の受注は完了した日に集計します。労働時間は日付ごとに入力します。

試作ではサンプルの担当者名と受注項目から始まります。従来の timer_app.py.rtf は変更していません。

## 検証

Chromium で8人の表示、開始・停止・再開、再読み込み後の状態復元、受注選択必須チェック、受注合計、労働時間・生産性、2列貼り付け、iPad/スマートフォン幅の横はみ出しなしを確認しました。実機 Safari とネイティブ iOS の検証は未実施です。
